# MLS Sekolah

MVP Manajemen Learning System berbasis Next.js dan JSON database lokal.

## Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Akun demo

Semua akun memakai password `123456`:

- `siswa` untuk role siswa
- `guru` untuk role guru
- `admin` untuk role admin
- `kepsek` untuk kepala sekolah
- `kurikulum` untuk kurikulum

Database berada di `data/db.json`. Route API di `app/api` menangani login, user, tugas, ujian, dan pengumpulan jawaban.
